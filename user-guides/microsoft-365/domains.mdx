Open **Cloud > Domains** to read Microsoft domain records. Existing `/m365/domains` links open Cloud Domains with Microsoft selected.

**Audience:** Company users with Microsoft 365 read access and MSP staff.

1. Confirm the company scope.
2. Select **Microsoft 365** in Provider when shown.
3. Find the domain with the Domain filter and read Verification, Services and Authentication.
4. Use Columns for Primary and Last synced, then Save Changes to apply the preference.

This is a reading page. Primary is the current default-domain indicator; there is no separate initial-domain badge or domain-editing action. Missing registrar expiry on a Microsoft row does not mean its registration never expires. Read the DNSimple row when one is available, or ask your MSP to check the registrar.

- [Read cloud and registrar domains](/user-guides/cloud/domains): fields, provider differences and summary counts.
- [Find and export domains](/user-guides/cloud/filter-domains): current filters and loaded-page CSV scope.
- [Review domain renewal information](/user-guides/cloud/review-domain-renewals): registrar fields and MSP follow-up.

Export CSV uses read access and downloads the loaded page with defined fields. There is no format chooser or column sorting on the current table. Ask your MSP to make provider changes; Company support requests start with the [Home AI Assistant](/user-guides/ticketing/open-a-ticket).
