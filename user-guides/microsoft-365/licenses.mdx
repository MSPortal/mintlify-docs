Microsoft 365 license inventory is now available in **Cloud > Licenses**. Existing `/m365/licenses` links open Cloud Licenses with Microsoft selected.

**Audience:** Company users with Microsoft 365 read access and MSP staff.

1. Open **Cloud > Licenses** and select the company you want to review.
2. Set **Provider** to **Microsoft 365** if that column is shown. It is omitted when only one provider is available.
3. Review **Assigned**, **Purchased**, **Available**, and **Renews / Expires**. Use **Columns** for **Status** and **Last synced**.
4. Click a license row to inspect its synchronized assigned users. Select one company first to keep the user list company-specific.

The current Cloud panel shows counts and assigned users. The instructions for the former Microsoft-only panel's included-service list and **Load more** control do not apply here.

## Current instructions

- [Read cloud license usage](/user-guides/cloud/licenses): counts, renewal dates, access, and capacity caveats.
- [Find, filter, and export licenses](/user-guides/cloud/filter-licenses): hidden allocations, spare seats, sorting, and the loaded-page CSV export.
- [View license assignments and combinations](/user-guides/cloud/view-license-assignments): user holders, domains, offices, and license sets.

To request an assignment or subscription change, contact your MSP through [a support ticket](/user-guides/ticketing/open-a-ticket). Viewing or filtering this inventory does not purchase or remove seats.
