**Audience:** MSP staff with Note Templates settings access. Open **Settings > Customization > Note Templates**. Reading, editing and management actions depend on your role.

## Choose a template type

Use **All** or a type tab to review the list. The supported types are Compliance Check Note, Planner Item, Meeting Agenda, Meeting Notes and Report Section. These are reusable content templates; notification email templates are managed separately in [Email settings](/user-guides/settings/email).

## Create or edit

1. Select **Add New Template**, or open an existing template's edit action.
2. Enter a name, choose the intended type and add the content. Add a description that helps other staff choose it.
3. Review the content in the editor. If an AI drafting option is offered, review its result before saving; generation is not itself a saved template.
4. Use the editor's save action. Wait for the result and reopen the template to confirm its type and content.

Opening Add New Template starts an editor; it does not immediately create a record. Read-only users can inspect a template without gaining permission to edit it. Do not assume arbitrary double-brace variables expand in every consuming screen; use only the capabilities offered for that workflow.

## Set a default

The default is chosen per template type. Use the row's default action. When replacing another default of that type, review and confirm the replacement prompt. Setting the first default or removing a default can save immediately.

If a replacement reports an error, refresh and inspect both templates before retrying. Clearing the previous default and assigning the new one can leave an intermediate state if an operation fails. A default is starting content for supported workflows; changing it is not a bulk rewrite of existing notes or meetings.

## Delete and recover

Use the template's delete action and review the confirmation. Check its name and type before confirming. If the wrong template appears in a picker, verify its type and default state before deleting it. If Save is disabled, check that the required name and content are present.

## FAQs

<AccordionGroup>
  <Accordion title="Are email templates managed here?">
    No. Note Templates covers compliance notes, Planner items, meeting agendas/notes and report sections. Use Email settings for notifications.
  </Accordion>
  <Accordion title="Does opening Add New Template create a record?">
    No. Save the editor to create the template.
  </Accordion>
  <Accordion title="Is there one default for every template?">
    Defaults are per template type. Review the replacement confirmation when another default exists.
  </Accordion>
  <Accordion title="Does changing a default rewrite existing notes?">
    No. A default supplies starting content in supported workflows; it is not a bulk rewrite.
  </Accordion>
</AccordionGroup>
