Manage external resources in **Settings > Dashboards > External Dashboards**. The older External Resources settings address opens this tab. Existing links and embedded reports use the same external-dashboard catalog.

## Before you start

This is an **MSP staff** configuration task. You need dashboard-settings access and the relevant write or management permission. Company users open resources made available by their IT provider; they do not administer this catalog.

An external resource can open a dashboard, knowledge base, training service, or another HTTPS page. Its name describes the destination; there is no category selector for Documentation, Tools, or Vendor on the current form.

## Add and review a resource

<Steps>
  <Step title="Open External Dashboards">
    Go to **Settings > Dashboards**, select **External Dashboards**, and wait for the table to load.
  </Step>
  <Step title="Create the catalog entry">
    Select **Add**. Enter a name and default HTTPS URL; review the optional description, display order, icon, and Company roles. Select **Create** to save, or Cancel to leave the unsaved form.
  </Step>
  <Step title="Assign the Company destinations">
    Use the row menu's **Company URLs** action when a company should have access. In a company context, an assigned Company URL is required; the default URL is not a fallback for a missing assignment.
  </Step>
  <Step title="Verify the intended reader">
    Open the resource in the intended company scope and check the applicable role. Confirm the destination itself works with that reader's external-service account.
  </Step>
</Steps>

Company role selections restrict Company readers. An empty role list does not mean staff-only: it imposes no explicit Company-role restriction. Assignments and other access checks still apply. Portal access does not grant access at the destination service.

## Save boundaries

| Action | When it takes effect |
| --- | --- |
| Catalog creation or edit | **Create** or **Update** saves the form. |
| Add, edit, or remove a Company URL | Saves separately in Company URLs. Closing the dialog is not rollback. |
| Enable/disable, default, or sidebar pin actions | Separate actions that affect the shared catalog/navigation. |
| Icon upload | Uploads before the catalog form is submitted; do not treat Cancel as upload cleanup. |
| Delete | Requires the displayed confirmation; review the exact selected resource or bulk selection. |

Use **Check Frame Policy** to request an embedding check. A result applies to the checked default destination; it does not prove every Company URL works. **Force Allow Embedding** cannot override a provider's browser security restrictions or sign-in requirements. When embedding is unavailable, use **Open in New Tab**.
