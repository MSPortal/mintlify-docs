**Audience:** MSP staff managing the shared Standards catalog. Deleting a definition affects more than the company currently selected.

Open **Settings > MSP Tools > Standards**. Review linked work in the [Standards matrix](/user-guides/msp-tools/read-standards-matrix) before removing a definition. Required/Optional changes and company deployment exceptions serve different purposes from deletion.

## Delete an individual standard

1. Expand its category and select the item's **trash**, labeled **Delete item**.
2. Read the confirmation carefully. The app checks how many Planner items are linked.
3. If linked work exists—or the count could not be checked—type the exact item name, including spacing and case. Use **Delete Item & Planner Items** to confirm.
4. If the check confirms no linked work, the simpler **Delete Item** confirmation appears.
5. Use **Cancel** before confirmation to keep the definition. After confirming, wait for the result and verify the catalog and affected Planner work.

<Warning>
Deleting an individual standard explicitly deletes its linked Planner items across companies, then removes the standard and company tracking. This is permanent removal, not archiving or marking a deployment unnecessary.
</Warning>

The deletion has multiple stages. If an error appears, inspect both the catalog and Planner before retrying; do not assume the entire operation rolled back.

## Delete a category

Use the category's **trash**, labeled **Delete category**, and review **Delete Category**. This confirmation warns that all items in the category will also be deleted. It does not use the individual-item typed-name check or show the same linked Planner count.

Category deletion removes its standards and company tracking. Its current deletion path can leave the previously linked Planner items in place with their Standards link cleared. Review those surviving items separately; do not assume this has the same result as deleting every item individually.

## Remove a tier or deployment option

Follow [Configure Standards tiers and deployment options](/user-guides/settings/standards-tiers). Option deletion is immediate and clears selections using it. Tier deletion requires confirmation, rejects tiers still used by options and clears company type targets for a successfully deleted tier.

## Keep a definition while changing its purpose

Use **Required** or **Require one of group** for scoring rules, and recorded company deployment statuses for a company's situation. These do not mean the catalog definition has been retired. Optional standards can still be synced into company tracking and Planner work.

This catalog has deletion controls; it does not offer a separate Archive action. If you need to preserve history, review the affected work with your MSP before deciding what to remove.

## FAQs

<AccordionGroup>
  <Accordion title="Where do I delete an individual standard?">
    Open Settings > MSP Tools > Standards, expand the category and use the item trash action.
  </Accordion>
  <Accordion title="Does deleting a standard affect only my selected company?">
    No. The shared definition and its linked work can affect companies across the MSP.
  </Accordion>
  <Accordion title="When must I type the standard name?">
    For an individual item with linked Planner work, or when the linked count could not be checked. Type the exact name.
  </Accordion>
  <Accordion title="Does a failed linked-count check mean zero items?">
    No. The app uses stricter confirmation because the linked count is unknown.
  </Accordion>
  <Accordion title="Does deleting an item archive its Planner work?">
    No. Individual-item deletion explicitly deletes linked Planner items before removing the definition and tracking.
  </Accordion>
  <Accordion title="Does category deletion use the same typed-name check?">
    No. It uses a category confirmation warning that all items in that category will be removed.
  </Accordion>
  <Accordion title="Does deleting a category delete all its old Planner work?">
    Do not assume that. The category path can leave Planner items with their Standards link cleared; review them separately.
  </Accordion>
  <Accordion title="Can I cancel after opening a delete confirmation?">
    Yes, before confirming. Cancel keeps the definition; it is not an undo for a completed deletion.
  </Accordion>
  <Accordion title="Does Optional prevent company tracking from being created?">
    No. Optional changes scoring. Sync can still create company tracking and Planner work.
  </Accordion>
  <Accordion title="What should I do if deletion reports an error?">
    Inspect both catalog and Planner records before retrying because the multi-stage operation may have partially completed.
  </Accordion>
</AccordionGroup>
