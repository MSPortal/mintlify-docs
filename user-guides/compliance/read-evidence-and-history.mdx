**Audience:** Company users and MSP staff with access to the assessment. This guide covers reading. If you also have editing permission, avoid changing controls while reviewing: assessment edits can autosave.

## Open the right assessment

1. Find the check in **Compliance > Tree** or **List**.
2. Select its title.
3. Check the company, run, group, and target shown in the title area or breadcrumb.
4. Review the status, priority, due date, and public notes.

On a wide desktop, guidance, assessment fields, and supporting tabs appear in separate columns. On a phone, use **Guidance**, **Details**, **Uploads**, and **History**. If supporting tabs are missing at an intermediate window width, widen the window or use the phone layout.

## Read Guidance

Available sections can include the requirement description, why it matters, how to check it, remediation guidance, remediation impact, references, criticality, frequency, and score weight. Sections without configured content can be absent.

These sections describe how the check is defined. They are not proof that the requirement has been tested or that the recommended remediation has been performed. Use the recorded assessment and its evidence for that context.

Reference custom fields attached to the check definition appear with guidance and are read-only in the assessment. Custom fields for the particular assessment are separate.

## Read notes and assessment fields

**Public Notes** contain information intended for Company readers. The MSP interface can also show **Private Notes** for internal work. Ask your MSP for a shareable explanation if the public findings are unclear.

Readers cannot edit the status, priority, due date, or notes. Users with additional write permission may see editable controls and save actions. A control’s presence does not mean you need to change it to read the assessment.

## Open supporting files

1. Select **Uploads**.
2. Find the relevant filename.
3. Select that file’s **Download** icon.
4. Wait for the download and open the file using an appropriate application.

An upload is supporting material supplied for the assessment; its presence alone does not establish a passing result. If a download fails, ask your MSP to check access or the file. Readers do not need to upload or delete anything to inspect available evidence.

## Review custom fields

On a wide desktop, select **Custom Fields** for the assessment’s fields. On a phone, these fields appear below the entries under **History**. Your MSP determines which fields exist and which are available to you.

Definition-level reference fields and assessment-level values answer different questions. For example, a reference field can describe the requirement while an assessment field records an observation for this run.

## Review earlier completed assessments

1. Select **History**.
2. Review earlier completed instances of the same check for the company, including completion date, recorded status, and completing user when available.
3. Use an entry’s view control to open that instance.
4. Check its run and target before comparing notes or results with the current assessment.

This panel excludes the currently open assignment and shows earlier completed instances. It is not a log of every edit, autosave, or status transition. An empty panel can simply mean no other completed instance is available.

Use previous instances for comparison. If editing controls are available, do not change an old assessment unintentionally; opening History is not a guarantee that every subsequent screen is locked against changes.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does History show every change to the current check?">
    No. This panel lists other completed instances of the check for the company. It is not a complete edit-by-edit audit log.
  </Accordion>
  <Accordion title="Why is my current result absent from History?">
    The panel excludes the assignment you already have open and looks for other completed instances.
  </Accordion>
  <Accordion title="Where are custom fields on a phone?">
    Assessment-level custom fields appear beneath the History entries. Definition-level reference fields appear with Guidance.
  </Accordion>
  <Accordion title="Why can I read guidance but find no supporting tabs?">
    The layout changes with width. At some intermediate widths the supporting pane is unavailable; widen the window or use the phone layout.
  </Accordion>
  <Accordion title="Does an attached PDF mean the check passed?">
    No. Review the recorded status, public findings, date, and relevance of the supporting file.
  </Accordion>
  <Accordion title="Can I read files without permission to upload?">
    The reader interface can offer Download while hiding upload and delete controls. File access is still required.
  </Accordion>
</AccordionGroup>
