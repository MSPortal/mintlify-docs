Use the **Cloud > Posture** overview when reviewing Global View or multiple companies. With exactly one company selected in the top bar, the page shows details directly and these list filters are absent.

**Audience:** Company users whose permitted scope includes a posture list and MSP staff reviewing companies. Microsoft 365 read access is required.

## Narrow the overview

1. Confirm the top-bar company scope.
2. Use **Company** to select companies within that scope. Search within its option popover if needed; selecting a Company column filter keeps the overview layout.
3. Use **Provider** when shown. Click the checkbox beside Microsoft 365 or Google Workspace and wait for the rows to update.
4. Open **Secure score** and choose **80% and above**, **50-79%**, or **Below 50%**. **All** clears that field.
5. Wait for the matching count. Use **Previous** and **Next** for additional pages of up to 20 snapshots.

Selections within Company or Provider are alternatives; different active fields must all match. Filters apply across list pages and return to page 1. The Provider column is based on the loaded results and can disappear after narrowing to one provider. **Clear Filters** restores table filters, including an entry-link provider, while keeping top-bar scope and access limits.

The displayed score is rounded to a whole percentage, while filtering uses a finer percentage. A value near a band boundary can therefore display 50% or 80% while matching the preceding band. Confirm the points in detail before treating this as an inconsistent score.

## Open the result

- Click a **Google Workspace** row for the calculated-checks dialog. Close it to return to the list.
- Click a **Microsoft 365** row or its score to open Secure Score for that company.
- Click an available **MFA**, **Domains** or **Devices** percentage to open that company's Current Posture.

Company selection in the top bar changes the overall scope; a Company table filter only narrows the list. Confirm the company again when entering another view.

## Recover missing results

Use **Clear Filters**, confirm the top-bar company selection, and reopen **Cloud > Posture** from navigation if results are still unexpectedly narrow. A bookmarked company-name search can remain active even after table filters are cleared; the current overview has no general search box to edit that constraint.

If records remain absent, ask your MSP to check read access, company mapping, enabled posture synchronization and whether a snapshot exists. An empty list does not prove that the company has no security issues. A previous snapshot can remain visible when a new collection is delayed.

There are no overview filters for Snapshot date, Checks, Last synced or the optional MFA/Domains/Devices measures. The table has no column sorting, CSV export or bulk remediation action. **Columns** changes visible fields after **Save Changes**; it does not change source data.

## FAQs

<AccordionGroup>
  <Accordion title="Why are there no filters when I select one company?">
    A single top-bar company opens details directly. Filters and pagination belong to the multi-company overview.
  </Accordion>
  <Accordion title="Can I search all posture fields from one box?">
    No. Use the Company option search and the Company, Provider and Secure score column filters. The current overview has no general search box.
  </Accordion>
  <Accordion title="Why did the Provider column disappear after filtering?">
    It uses providers present in the loaded results and can disappear when only one remains. Clear Filters restores table filtering; top-bar scope still applies.
  </Accordion>
  <Accordion title="Why can a displayed 80% score appear in the 50-79% band?">
    Display rounds to a whole percentage while the filter uses finer precision. For example, a score just below 80 can display 80%. Review the points in detail.
  </Accordion>
  <Accordion title="Does Clear Filters remove a bookmarked company-name search?">
    Not necessarily. A search carried by the entry link remains a separate constraint. Reopen Cloud > Posture from navigation and confirm the company scope.
  </Accordion>
  <Accordion title="Does a Company column filter open the single-company detail layout?">
    No. Only choosing exactly one company in the top bar changes that layout. The column filter narrows the overview rows.
  </Accordion>
  <Accordion title="Can I export or sort the posture overview?">
    The current overview offers neither CSV export nor column sorting. Use the available filters and detail views.
  </Accordion>
  <Accordion title="Does filtering the overview change provider settings?">
    No. Filters only choose the snapshots displayed. They do not synchronize, remediate or change security configuration.
  </Accordion>
</AccordionGroup>
