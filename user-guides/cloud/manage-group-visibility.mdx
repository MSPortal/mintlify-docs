Use **Cloud > Groups** to control client visibility of synchronized groups. **Client visible** affects Company readers and Company ticket-form group choices; MSP readers continue to see hidden groups.

**Audience:** MSP staff with Microsoft 365 write or management access. Company users should ask their MSP for visibility changes. This guide describes the MSP workflow; availability follows the assigned permissions.

## Hide or show one group

1. Open **Cloud > Groups** and confirm the company scope.
2. Find the exact group; check its company, email and type before changing it.
3. In **Client visible**, turn the switch off to mark it **Hidden**, or on to mark it **Visible**.
4. Wait for the update to finish and verify the resulting state. The switch saves immediately; there is no separate Save button or confirmation dialog for this change.
5. Review the relevant Company experience and ticket-form options after the update. An MSP session still sees hidden groups, so it cannot demonstrate what the client sees.

If the column was hidden through Columns, show it and save that preference first. Read-only accounts do not receive visibility write controls. A failed update displays **Could not update group visibility**; check the resulting state before retrying.

Hiding changes portal visibility. It does not delete the provider group, disable accounts, remove memberships, or revoke access to provider resources. Group synchronization preserves an existing visibility choice; newly synchronized groups start visible until curated.

## Hide security groups in bulk

1. Use the **top-bar company selector** to choose the companies whose groups should change. A broad Global View can affect every permitted company.
2. Confirm that **all Security and Mail-enabled security groups in that scope** should be hidden from Company users.
3. Click **Hide all security groups**. It runs immediately, without a confirmation dialog.
4. Wait for the completion notification, then verify the affected groups. A zero count can mean no groups needed a visibility change.

<Warning>
The bulk action ignores table filters and pagination, including the Company column filter. A name search, a Google-only provider filter, or an empty filtered list does not limit it. Use the top-bar company selector to set its scope. There is no bulk Undo or Show all button here; restore a group with its individual Client visible switch.
</Warning>

This button targets **Security** and **Mail-enabled security** classifications. It does not hide Google groups, Microsoft 365 groups, or Distribution groups merely because they are currently visible in the table.

## How visibility and ticket templates combine

A Company's ticket-form group picker combines the selected company, client visibility, and the field's provider/type configuration. Making a group Visible does not force it into every template. A hidden group is omitted from Company picker searches and no longer resolves as a selected group label for Company users. MSP readers can still see the hidden group.

Treat this as client presentation control, not as a provider security control. For actual membership or access changes, use your provider administration workflow and verify the result there.

## FAQs

<AccordionGroup>
  <Accordion title="Does hiding a group delete it or remove members?">
    No. It changes client visibility in MSPortal. Provider group existence, membership and resource access are unchanged.
  </Accordion>
  <Accordion title="Why can I still see a group after hiding it?">
    MSP readers continue to see hidden groups. Check the Client visible state and verify the actual Company experience separately.
  </Accordion>
  <Accordion title="Do I need to press Save after changing Client visible?">
    No. The switch saves immediately. Save Changes in Columns is a separate preference operation.
  </Accordion>
  <Accordion title="Does Hide all security groups respect my table filters?">
    No. It uses the top-bar company scope across pages and ignores table filters, including the Company column filter.
  </Accordion>
  <Accordion title="Which group types does the bulk button hide?">
    Security and Mail-enabled security. It does not target Google group, Microsoft 365, or Distribution classifications.
  </Accordion>
  <Accordion title="How do I undo a bulk hide?">
    There is no bulk Undo or Show all control. Find each group that should be visible and turn its Client visible switch on.
  </Accordion>
  <Accordion title="Will the next group synchronization undo my visibility choices?">
    Existing visibility choices are preserved by synchronization. Newly imported groups start visible and may need curation.
  </Accordion>
  <Accordion title="Why is a Visible group still missing from a ticket form?">
    The template can restrict provider and group type, and the picker follows the selected company. Check those settings, mapping and synchronization as well as client visibility.
  </Accordion>
</AccordionGroup>
