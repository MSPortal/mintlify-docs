Click **Export CSV** on **Cloud > Users** to download the accounts matching your current company scope and column filters. The export gathers matching users across list pages, including pages you have not opened.

**Audience:** Company users with Microsoft 365 read access and MSP staff. You do not need Microsoft 365 management permission to use this export.

## Download the CSV

1. Open **Cloud > Users** and confirm the company scope.
2. Apply the filters you need. **Status = Enabled** is the default; choose **All** before exporting if you also need disabled accounts.
3. Click **Export CSV** above the table.
4. Wait for **Exporting users…** progress and the completion notification. Keep the page open until the download finishes.
5. Open the downloaded CSV and check its record count and fields before using it for a review.

## What the file contains

The defined export fields are **Name**, **Email**, **Provider**, **Company**, **Office**, **Department**, **Job title**, **Account type**, **Status**, **Licenses**, **License count**, **Last sign-in**, and **Last synced**.

Hidden columns are still included in the CSV. License names are separated by semicolons in the Licenses field; the list is not limited to the one badge shown inline on screen. Missing values can be blank. A user with no stored display name can have a blank Name in the CSV even when the table displays an email fallback.

The export does **not** include 2-step verification flags or a separate Administrator flag. **Account type** is the underlying directory type, so a Google row labeled Administrator on screen can export as Member. Use the provider's appropriate records with your MSP for a security or administrator review.

<Note>
Cloud Users exports all matching pages. The separate Cloud Licenses inventory currently exports only its loaded list page. The same Export CSV label does not imply identical scope on every module.
</Note>

## If no file arrives

If no users match, broaden the filters first. If an error appears, wait and retry; do not treat a failed or empty export as evidence that there are no accounts. Check the browser's download list if the completion notification appeared but the file is not obvious. Contact your MSP if the export keeps failing.

## FAQs

<AccordionGroup>
  <Accordion title="Does Export CSV include users on pages I have not opened?">
    Yes. Cloud Users gathers matching rows across list pages using the current scope and filters. It is not limited to the 50 users on the visible page.
  </Accordion>
  <Accordion title="Will hidden columns or hidden license badges be missing from the file?">
    No. The CSV has defined fields independent of column visibility and includes the full recorded license-name list. It still follows the active filters.
  </Accordion>
  <Accordion title="Do Company users need management permission to export?">
    No. Microsoft 365 read access allows this export for the company data you can access. Ask your MSP if you cannot see Export CSV.
  </Accordion>
  <Accordion title="Why are disabled users absent from my export?">
    The table begins with Status = Enabled, and the export follows that filter. Choose Status = All or Disabled before exporting, depending on the review you need.
  </Accordion>
  <Accordion title="Does the CSV include Google 2-step verification or administrator status?">
    No. It does not export those flags. Account type is the underlying directory type and can differ from an Administrator badge displayed in the table.
  </Accordion>
  <Accordion title="Is this export a live record of every account in the provider?">
    No. It exports synchronized records available to your account and matching your filters. Check Last synced, company mappings, and provider status with your MSP when completeness matters.
  </Accordion>
</AccordionGroup>
