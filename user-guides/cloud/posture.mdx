Open **Cloud > Posture** to read the latest stored Microsoft 365 and Google Workspace posture information available for your company. The page summarizes synchronized evidence; it is not a live security audit or a guarantee that an environment is secure.

**Audience:** Company users with Microsoft 365 read access and MSP staff. Company users ask their MSP to change access, provider settings or security configuration.

## Open your company's posture

1. Open **Cloud**, then **Posture**.
2. Confirm the company selected in the top bar. If you can select companies, choose the company you want to review.
3. With one company selected, read its available details directly: Google calculated checks, Microsoft Secure Score, or both. There is no separate one-row overview table.
4. With Global View or multiple companies selected, use the overview table. Open a Google row for its checks dialog; open a Microsoft row or its score for the company's Secure Score page.
5. Check the provider and snapshot date before interpreting a score. Ask your MSP about missing or old information.

A company can have one latest row for each provider. A connected company without a stored snapshot can be absent. Selecting a company with no available snapshot shows an empty-state message.

## Read the overview

| Field | Meaning |
| --- | --- |
| **Company** | Company associated with the snapshot. |
| **Provider** | Microsoft 365 or Google Workspace. The column can disappear when the loaded results contain only one provider. |
| **Secure score** | Rounded percentage from the stored points. Microsoft rows use Microsoft Secure Score; Google rows use the MSPortal calculation. |
| **Snapshot date** | Date of the stored snapshot. It does not prove every underlying signal was collected on that date. |
| **Checks** | Number of stored Google checks, or Microsoft controls for a Microsoft row. |
| **Last synced** | Hidden by default; show it through **Columns**, then **Save Changes**. This is the main snapshot's timestamp. |

The current table has no separate Score source column. The Google detail identifies its source as **MSPortal**. Microsoft details are on **Secure Score**. Always identify the provider before comparing percentages.

## Choose a Microsoft view

When Microsoft 365 is connected, the available navigation can include:

- **Overview**: the multi-company snapshot table; omitted for one selected company.
- **Secure Score**: Microsoft controls and score detail.
- **Current Posture**: additional Microsoft posture information when the required CIPP integration and feature are available.

You do not need to select Microsoft in a Provider filter before opening Secure Score from the portfolio navigation. A Google-only entry can omit Microsoft view links.

Some Microsoft overview rows also show **MFA**, **Domains** and **Devices** percentages from Current Posture data. These columns require the integration and available values on the loaded page. Click a populated percentage to open that company's Current Posture. They are separate measures, not components added to Microsoft Secure Score. A dash or omitted column does not establish a pass. The overview's Last synced field is not a separate freshness timestamp for each of these measures.

## Follow up on a finding

Company users should [start with the Home AI Assistant](/user-guides/ticketing/open-a-ticket) to request help. Include the company, provider, snapshot date, check or control, and the concern. MSP staff verify the provider evidence and plan changes in the appropriate workflow.

The overview and Google checks have no security-setting edit, run-now, CSV export or history selector. Microsoft detail and Current Posture are separate workflows; opening a row does not itself fix a finding.

## FAQs

<AccordionGroup>
  <Accordion title="Why do I see details instead of a company table?">
    Exactly one company is selected. Posture shows that company's available Google checks and Microsoft Secure Score directly. Broader company scope uses the overview table.
  </Accordion>
  <Accordion title="Do Microsoft and Google use the same score calculation?">
    No. Microsoft rows use Microsoft Secure Score; Google rows use MSPortal's six-check calculation. Similar percentages are not equivalent evidence.
  </Accordion>
  <Accordion title="Where did the Score source column go?">
    The current overview combines the percentage under Secure score. Use Provider and the detail view to identify its source; Google's detail shows MSPortal.
  </Accordion>
  <Accordion title="Why is Current Posture missing?">
    It is a Microsoft view requiring the CIPP feature and integration. It is not part of the Google checks screen. Ask your MSP about availability.
  </Accordion>
  <Accordion title="Why are MFA, Domains or Devices columns missing?">
    They require the relevant integration and populated data on the loaded page. Missing values are not a clean security result.
  </Accordion>
  <Accordion title="Can I see every day's Google score in this overview?">
    No. It shows the latest stored snapshot per company and provider and has no date-history selector. Older snapshot storage does not make history browsing available here.
  </Accordion>
  <Accordion title="Does a new Snapshot date mean every input is current?">
    No. Google reporting signals can lag behind the sync date, and other providers have their own collection schedules. Check the evidence with your MSP.
  </Accordion>
  <Accordion title="Can a Company user fix a security setting from the overview?">
    No. Start with the Home AI Assistant to request MSP help, including the provider, date and finding. This reader does not change provider security settings.
  </Accordion>
</AccordionGroup>
