Use **Export PDF** on an internal dashboard to download a visual snapshot of its current content. It is a static document, not an interactive dashboard or an export of every underlying record.

**Audience:** Company users with dashboard access and MSP staff. Sharing the downloaded file is a separate action; the button does not email or publish it.

## Prepare and download

<Steps>
  <Step title="Check the view">
    Open the dashboard, select the intended company scope, and choose the relevant date preset. Check each widget’s printed dates; fixed-window summary cards and widget overrides can use different periods.
  </Step>
  <Step title="Make the content readable">
    Wait for charts to finish loading. Use the **½**, **⅓**, or **¼** width control to choose a useful arrangement. Check for missing-data messages and errors before exporting.
  </Step>
  <Step title="Export">
    Select **Export PDF** and wait for the browser download. The button shows **Exporting...** while it runs. The filename contains the dashboard name and export date.
  </Step>
  <Step title="Review the file">
    Open the PDF and inspect every chart, label and value. Confirm that it represents the intended company and reporting period before sharing it.
  </Step>
</Steps>

<Warning>
The current PDF export can lose card styling and overlap or clip chart labels. A downloaded file is not proof of a clean export. If the layout is unsuitable, ask your MSP for another report and include the dashboard name and affected chart when reporting the problem.
</Warning>

## What the file contains

The export fits dashboard content into a single PDF page. Large dashboards can become difficult to read. The dashboard header, selected company and date-menu controls are outside the captured content, so the PDF alone may not identify all the context you used. Record the intended company and reporting period when sharing it.

The filename’s date is the export date, not the start or end of every metric’s reporting window. Summary cards keep their own periods. A widget with a configured date override can also differ from the header selection.

You cannot click charts in the PDF to open ticket lists. Open the live dashboard and use [ticket drilldown](/user-guides/dashboards/inspect-dashboard-tickets) to inspect records. This PDF is not a CSV export and does not include every paginated ticket row.

External dashboards use the connected site’s own viewing or document options. Do not assume the internal dashboard Export PDF control applies to an embedded external service.

## Troubleshooting

| Problem | Next step |
| --- | --- |
| No file appears | Wait for Exporting to finish and check the browser’s downloads and any download-blocking message. |
| **Export Failed** appears | Capture the error text and ask the MSP to investigate. Keep the dashboard, company and date selection with the report. |
| Labels overlap, cards lose styling, or content is clipped | Do not treat the file as ready to share. Report the affected chart and request another report if needed. |
| The PDF is too small to read | The content is fitted to one page. Try a simpler view or request a report designed for document output. |
| Company or reporting period is unclear | Check the live dashboard and include that context when sharing; the filename is insufficient. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I download a dashboard PDF?">
    Open an internal dashboard and select Export PDF in the header. Wait for the browser download, then inspect the file.
  </Accordion>
  <Accordion title="Does Export PDF email or publish the dashboard?">
    No. It downloads a file in your browser. Sharing or sending that file is a separate action.
  </Accordion>
  <Accordion title="Is the downloaded PDF interactive?">
    No. It is a static visual snapshot. Open the live dashboard to use chart drilldowns or change filters.
  </Accordion>
  <Accordion title="Does the PDF contain every ticket behind a metric?">
    No. It captures the displayed dashboard content, not every underlying or paginated record. Use the live ticket list to inspect records.
  </Accordion>
  <Accordion title="Why are PDF labels overlapping or card styles missing?">
    The current export has layout limitations. Review the file before sharing, report the affected chart, and request another report if it is not readable.
  </Accordion>
  <Accordion title="Why is a large dashboard so small in the PDF?">
    The dashboard content is fitted onto a single PDF page. A report designed for document output may be more suitable.
  </Accordion>
  <Accordion title="Does the export date in the filename describe the reporting period?">
    No. It is the export date. Check widget dates, fixed summary-card periods and any configured widget overrides.
  </Accordion>
  <Accordion title="Does the PDF clearly include my selected company?">
    The header and company selector are outside the captured content. Confirm the company in the live view and include that context when sharing.
  </Accordion>
  <Accordion title="Can I use this button to export an external dashboard?">
    External dashboards use the connected site’s own options. The internal dashboard Export PDF control does not promise an export from that service.
  </Accordion>
  <Accordion title="What should I report when export fails?">
    Provide the dashboard name, selected company, date selection and visible error. A failed export is not a completed download.
  </Accordion>
</AccordionGroup>
