**Audience:** Company users with Planner access and MSP staff. Company users see only work available to their account; your MSP manages access and client visibility.

## Open the archived list

1. Open **Planner > List View**.
2. Check the company scope and any active table filters.
3. Select **Archived** in the page header. When selected, the table shows archived items only.
4. Search the **Title** column or use the other available table filters.
5. Select an item title to read its details. Your access determines which fields and actions appear.
6. Select **Archived** again to return to the active list.

The Archived switch changes the list immediately; there is no Save step. It also returns to the first page and clears row selection. Existing table filters can still narrow the archived results, so review them if an expected item is missing.

## Understand what changed

| Item state | Meaning |
| --- | --- |
| Archived | Set aside from the active Planner list. An authorized editor can restore it. |
| Completed or Cancelled | A work status. Changing status does not by itself move an item to Archived. |
| Hidden from clients | Client visibility is off. Company users cannot reveal it by selecting Archived. |
| Deleted | Removed from Planner. The Archived switch does not recover deleted items. |

Archiving keeps the item and its planning details. It does not mark the work Completed, cancel a provider project or close a linked ticket. Read the item's status and related records separately.

## If you cannot find the item

Check both active and archived lists, the current company, and the table filters. If it is still missing, ask your MSP whether it was deleted, moved outside your access, or hidden from clients. An empty list can also follow a loading error; check for an error message before concluding there is no work.

Company users who need an item restored should ask their MSP unless their assigned permissions include the relevant editing action. Company administrator status alone does not grant every Planner action.

## FAQs

<AccordionGroup>
  <Accordion title="Where can I find old Planner work?">
    Open Planner > List View, select Archived and search the Title column. Check the current company and filters.
  </Accordion>
  <Accordion title="Does Archived show both active and archived work?">
    No. When selected, it shows archived items only. Select it again for the active list.
  </Accordion>
  <Accordion title="Is Completed the same as Archived?">
    No. Completed is a status; archiving is a separate action. A completed item can remain in the active list.
  </Accordion>
  <Accordion title="Can Archived reveal an item hidden from Company users?">
    No. Your company access and client visibility still apply.
  </Accordion>
  <Accordion title="Will changing the Archived switch save anything?">
    It changes the view and clears row selection. It does not archive, restore or edit an item.
  </Accordion>
  <Accordion title="Can I recover a deleted item from Archived?">
    No. Restore applies to archived items, not deleted ones. Ask your MSP if an expected item is missing.
  </Accordion>
  <Accordion title="Why is the archived list empty?">
    Check company scope and filters, wait for loading and review any error. Your MSP can confirm whether the item is archived, deleted or outside your access.
  </Accordion>
</AccordionGroup>
