## How to Use These Guides

### Choose the right audience and task

These are MSP administration and workflow guides. Start with the current task, then check its prerequisites, scope and Save behavior. Company access has its own permission and visibility requirements; an MSP screenshot is not evidence of Company access.

### Finding Information

<Steps>
  <Step title="Browse by Module">
    Select the guide for the module you're working with from the sidebar or cards above
  </Step>
  <Step title="Use Search">
    Press `Ctrl+K` (or `Cmd+K` on Mac) to search for specific topics
  </Step>
  <Step title="Check Prerequisites">
    Review any prerequisites at the start of each procedure
  </Step>
  <Step title="Follow Along">
    Use the step-by-step instructions with screenshots where available
  </Step>
</Steps>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where should a new MSP administrator start?">
    Start with Quick Start and the MSP Setup Playbook, then use Launch Center for your selected goals and rollout companies.
  </Accordion>
  <Accordion title="Are MSP screenshots the same as the client experience?">
    No. MSP staff can have administration controls and portfolio views unavailable to Company users. Check the audience and permission requirements in each guide.
  </Accordion>
  <Accordion title="Where are provider setup instructions?">
    Open the Integration setup directory, choose the intended provider and check the prerequisites and mapping steps for that connection.
  </Accordion>
</AccordionGroup>
