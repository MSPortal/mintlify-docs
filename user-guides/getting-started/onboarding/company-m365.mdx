**Audience:** MSP staff with integration access and an authorized Microsoft tenant administrator for consent.

## Connect the right companies

1. Open the Microsoft 365 step in **Launch Center**, or the Microsoft 365 company connection area under **Settings > Integrations**.
2. Identify the intended MSPortal company and the Microsoft tenant it should connect to. Check existing mappings before creating another connection.
3. Follow the offered connection and administrator-consent workflow. Review the actual requested permissions and target tenant before authorizing it.
4. Return to the connection list and inspect the saved connection status. A completed browser redirect is not sufficient evidence of a healthy connection.
5. Review synchronization and the company's expected Microsoft 365 data. Import and user-access configuration are separate from granting consent.
6. Return to Launch Center and inspect the company-specific findings.

Do not use a short generic permissions list as the complete consent specification. Required permissions depend on the offered integration capabilities and the actual Microsoft consent screen.

## Match the rollout scope

A pilot can focus on its selected company. For a wider rollout, the readiness check requires healthy Microsoft 365 connections for the rollout companies and any explicitly selected Microsoft 365 companies. Connecting one company does not complete every other company's requirement.

## Troubleshooting

If consent succeeds but the connection remains unhealthy, check its result and intended tenant before repeating consent. If users are missing, review synchronization, company mapping and import eligibility. If a company should be outside this rollout, correct the plan's scope; do not connect an unrelated tenant simply to clear the finding.

## FAQs

<AccordionGroup>
  <Accordion title="Does one Microsoft 365 connection complete a wider rollout?">
    No. Review healthy connection evidence for every required rollout or explicitly selected company.
  </Accordion>
  <Accordion title="Does consent automatically grant imported users portal access?">
    No. Review user import, company assignment and access groups separately.
  </Accordion>
  <Accordion title="Is the browser redirect proof of a healthy connection?">
    No. Check the saved connection status and subsequent synchronization.
  </Accordion>
</AccordionGroup>
