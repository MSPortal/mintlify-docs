**Audience:** MSP staff with Ticket settings access. The client-ticketing launch track separates delivery, visibility and request templates. It is not limited to a PSA status-mapping checklist.

## Configure ticket delivery

1. Open the ticket-delivery step in **Launch Center**, or **Settings > Tickets**.
2. Review the ticket creation method and its destination. For email delivery, configure the receiving address or the fallback used by that method.
3. For PSA delivery, verify the selected PSA connection and configure the fallback email address.
4. Save using the displayed settings action and wait for the result. Check delivery separately with the intended request workflow before rollout.

A readiness pass checks configuration evidence; it does not prove a test message arrived or a PSA created a ticket.

## Review visibility

Open the ticket-visibility step and review display groups for the primary PSA. Configure access for the intended Company groups and supported ticket categories. Do not assume a single fixed set of four status categories applies to every provider.

## Make a request template available

Open the template step and review an appropriate enabled template. Confirm company scope, audience visibility and any company-specific enablement override. A template available only to staff does not satisfy the client request requirement.

Every rollout company needs an enabled, client-available template that applies to it. A global template can cover companies only where the effective settings allow it. Follow [create a ticket template](/user-guides/ticketing/how-to-create-a-ticket-template) for authoring and save details.

## Verify the client path

Review the actual Company role's ability to start a request from Home or Tickets, choose an available template and reach the review/submission flow. A draft is not a submitted ticket. If readiness is blocked, distinguish missing delivery configuration from missing visibility or template evidence instead of changing all three at once.

## FAQs

<AccordionGroup>
  <Accordion title="Does client ticketing require a PSA?">
    The delivery configuration supports email and PSA paths. Configure the selected method and its required destination or fallback.
  </Accordion>
  <Accordion title="Does a delivery readiness pass prove a ticket was received?">
    No. It checks stored configuration; verify actual delivery separately.
  </Accordion>
  <Accordion title="Does a staff-only template satisfy client readiness?">
    No. Each rollout company needs an enabled template with applicable client visibility and effective company settings.
  </Accordion>
</AccordionGroup>
