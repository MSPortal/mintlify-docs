**Audience:** MSP administrators with Email settings access and someone authorized to manage the sending domain's DNS.

## Add and verify the domain

1. Open **Settings > Email > Sending Domain**. Review any existing domain before adding another configuration.
2. Enter the intended domain and select **Add Domain**. This creates the sending-domain configuration.
3. Copy the DNS record types, names and values displayed for that domain into your DNS provider. Use those exact values; generic SPF or DKIM examples are not a substitute.
4. Select **Check Verification** after the records are available. Inspect the resulting status; the action can return pending instead of verified.
5. Use **Refresh Status** to retrieve the current state. Resolve incorrect or missing records before repeatedly submitting verification.
6. Review **Default From Address** and save its change using the adjacent control. Domain verification and sender-address saving are separate actions.

There is no guaranteed propagation time. Your DNS provider and the displayed verification result determine when the configuration is ready. Verification improves sender authentication but does not guarantee inbox placement.

## Understand the boundaries

A sending domain identifies outbound messages. It does not configure ticket delivery, the support mailbox or inbound receiving. Those are separate settings. Launch Center's support-identity check requires the support email; it is not a sending-domain verification check.

## Remove or replace a domain

**Remove Domain** opens a confirmation describing the effects. Review it before confirming: this changes the organization's sending configuration. A refresh does not undo a removal, and removing the MSPortal configuration does not automatically clean up records at your DNS provider.

If verification remains pending, compare the exact displayed record name and value with DNS, including any hostname suffix the DNS provider appends. Ask the domain administrator to review conflicting records rather than copying an example from another tenant.
