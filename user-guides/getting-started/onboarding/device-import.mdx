**Audience:** MSP staff with integration-management access. Complete the selected RMM connection and company/site mapping first. The launch device workspace can also use Addigy when selected without a primary RMM.

## Review and import

1. Open the device step in **Launch Center**, or the provider's import area in **Settings > Integrations**.
2. Check the provider instance and synchronization status. Review staged devices and the source company/site.
3. Confirm company mappings before importing. A similar company name is not sufficient evidence that the records belong together.
4. Review device-type mappings and ignored categories. Use the displayed import controls for the intended records and wait for the result.
5. Open the actual **Devices** inventory for the target company and confirm imported records and their source.
6. Return to Launch Center and inspect the device finding for each rollout company.

Mapping changes and imports can persist independently. In supported mapping screens, **Map with AI** saves generated device-type mappings immediately; inspect the result before importing. Do not treat it as a draft preview.

## What counts as ready

The check looks for actual devices belonging to every rollout company and matching the selected primary RMM or applicable Addigy source. Pending staging rows, an unrelated manually entered device or a healthy integration alone do not prove that requirement is met.

Review ignored categories when a device count appears lower than expected. Excluded records may deliberately remain outside the import. Import only the intended pilot scope before expanding the rollout.

## Troubleshooting

If the staged list is empty, check synchronization and provider scope. If devices exist in staging but not inventory, check mapping, ignored types and the import result. If inventory exists but readiness still fails, check the selected provider and company rather than importing duplicates.

## FAQs

<AccordionGroup>
  <Accordion title="Do staged devices count as imported inventory?">
    No. Verify actual Devices records for the selected source and rollout company.
  </Accordion>
  <Accordion title="Does one imported device satisfy a wider rollout?">
    No. The check requires matching device evidence for every rollout company.
  </Accordion>
  <Accordion title="Is Map with AI a draft preview?">
    No. Supported device-type mapping screens save its generated mappings immediately.
  </Accordion>
