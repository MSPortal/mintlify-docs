**Audience:** MSP staff. Company users contact their IT provider if training is missing. Managing Premium access requires **Manage Training**; changing available courses also requires the relevant Training settings permission.

Training setup has three separate decisions: which companies and users have Premium access, which courses are available, and which courses or learning paths learners are assigned. Completing one does not automatically complete the others.

## Set the company Premium default

1. Open **Settings > Companies** and find the intended company.
2. Review the **Training** column.
3. Open the company row menu and choose **Enable Premium Training** or **Disable Premium Training**.
4. Wait for the result and review the updated company state. This is an immediate action, not an unsaved draft.

For several companies, select their rows and use the corresponding bulk action. Review the selected companies before applying it.

Premium training can affect billed usage. Review your actual subscription and usage in [Billing settings](/user-guides/settings/billing). Disabling access does not establish that earlier usage or a billing high-water mark has been removed.

## Review individual user overrides

Open **Settings > Company Users** and locate the user. The **Premium Training** column shows effective On/Off access and whether it comes from a **User override** or **Company default**.

Use the user row's Premium training action to enable, disable or inherit the company default. The corresponding bulk actions work on selected users. These actions save immediately. Choose **Inherit** when you want future company-default changes to apply; explicitly Off is not the same as inheritance.

A company-default change does not erase user overrides. If a user's access seems inconsistent with the company, inspect the source shown in this column.

## Choose the available courses

Open **Settings > Training**. Confirm company scope, find the intended courses and use their **Enabled** switches or a reviewed bulk selection. The Launch training setup view separately offers **Enable All Included Training** for organization-wide included content; it is broader than a visible table page.

See [Training settings](/user-guides/settings/training) for previews, custom course creation and the content-upload boundary. Premium entitlement does not guarantee every Premium course is enabled, assigned or available in the current catalog.

## Assign and verify

Use the Training assignment workflow or [Learning Paths](/user-guides/training/learning-paths) to assign the intended learners. Review course and path scope before adding a group. Then verify that a representative learner can see and launch the course and that progress is recorded.

A staff preview verifies the content view only. It does not validate Company permissions, Premium entitlement, assignment or a completed learning attempt. Configure reminders through the actual available workflow; enabling Premium does not by itself schedule a reminder campaign.

## Troubleshooting

For missing courses, check the user's effective Premium access, course enablement, company scope, training permission and assignment. For unexpected access after a company change, check user overrides. For an unexpected bill, compare the billed period and usage measure rather than only today's enabled-user count.

## FAQs

<AccordionGroup>
  <Accordion title="Does enabling Premium assign all courses?">
    No. Premium entitlement, course availability and assignment are separate decisions.
  </Accordion>
  <Accordion title="Why is a user still Off when the company is Premium?">
    Check for an explicit user override. Choose Inherit if the user should follow the company default.
  </Accordion>
  <Accordion title="Is Off the same as Inherit?">
    No. Off is an explicit user setting; Inherit follows the company default.
  </Accordion>
  <Accordion title="Do Premium changes wait for a page Save?">
    No. Company and user Premium actions save immediately.
  </Accordion>
  <Accordion title="Does disabling Premium remove earlier billed usage?">
    Do not assume it does. Review the actual billing period, usage measure and subscription.
  </Accordion>
  <Accordion title="Does a successful staff preview prove Company access?">
    No. Verify an actual learner’s scope, permissions, entitlement and assignment separately.
  </Accordion>
</AccordionGroup>
