Open **Projects** to review work across the companies you can access. MSPortal combines synced PSA projects with project updates, milestones, decisions, action items, and deliverables.

## Before you start

Your role determines which project views and editing controls are available. Select a company in the company selector to focus the portfolio, or use **Global View** to see the companies available to you. Projects and their available detail depend on your connected PSA and project settings.

<Note>
Screenshots show the MSP staff experience using Demo data. Client access is limited by company scope, role permissions, and **Settings > Projects > Client project access**.
</Note>

## Choose a portfolio view

| View | Use it to |
| --- | --- |
| **Dashboard** | Review portfolio health, the evidence behind each metric, and projects needing attention. |
| **Cards** | Scan project summaries, dates, hours, contacts, and the next action. Displayed fields depend on project settings. |
| **List** | Compare projects in a table and choose visible columns. |
| **Kanban** | Review projects by their configured PSA status groups. |
| **Schedule** | See dated projects and their scheduled work on a calendar. |

### Find a project

<Steps>
  <Step title="Choose the company scope">
    Use the company selector at the top of the app. Then open **Projects**.
  </Step>
  <Step title="Narrow the portfolio">
    In Cards, List, or Kanban, use the search field to search projects, companies, or outcomes. Choose **Open**, **Closed**, or **All**; Open is the initial selection. Use **Project Manager**, **Date**, or **Filters** to narrow the results further.
  </Step>
  <Step title="Open the project">
    Select a project card or list row to open its workspace. Clear filters or switch to **All** if you cannot find an older project.
  </Step>
</Steps>

The health filters distinguish **Needs Input**, **Blocked**, **At Risk**, **On Track**, and **Unscored**. Needs Input highlights pending client input; a project can also have a separate health classification.

## Understand portfolio health

The **Dashboard** includes **Active schedule**, **On-time delivery**, and **Effort adherence**. Each metric shows its eligible project count; missing evidence does not mean a project is healthy.

- **Active schedule** considers open projects with due dates that are not overdue.
- **On-time delivery** considers projects completed on or before their due date in the last 12 months.
- **Effort adherence** considers projects at or below 110% of estimated hours.
- **Unscored** means an open project lacks both a due date and enough hours information to calculate health.

Review **Projects needing attention** and any source-freshness warning alongside the score. Administrators control which exact PSA statuses participate under **Settings > Projects > Client project access > Project health status**.

## Work with project Kanban

Portfolio Kanban groups whole projects. The **Kanban** tab inside an individual project groups its tickets instead.

With status-edit permission, drag a project to a destination column. MSPortal uses the configured default status where available or asks you to select a target PSA status. A successful status change is written to the supported PSA integration. Review the destination before completing the move.

<Tip>
Column names are configurable. If a project is missing from a grouped board, check **Status Mapping** for unmapped PSA statuses or use **Use Raw PSA Statuses** to display original status names.
</Tip>

## Troubleshooting

| Problem | What to check |
| --- | --- |
| No projects appear | Company scope, Open/Closed selection, search and filters, and the PSA integration's project sync. For client users, also check client project access and individual project visibility. |
| A view or edit control is missing | Your role's project permissions and the project's PSA support. |
| Fields or phases are missing | **Settings > Projects > Display Configuration**, plus whether the project contains phases or tickets. |
| Health looks incomplete | Eligible sample counts, Unscored projects, source freshness, and active/inactive health statuses. |
