Connect **QuoteWerks Web** through **Settings > Integrations**. Its wizard has three steps: **Connect**, **Map**, and **Complete**. Map customers to the correct portal companies before checking their quotes.

**Audience:** MSP staff with integration-management access. Company users read quotes and ask their MSP to repair connections, mappings, or permissions.

## Before you start

Ask your QuoteWerks Web administrator for an API key with the required **MasterRights** access and the correct API base URL. This integration uses the QuoteWerks Web API; a QuoteWerks Desktop installation alone is not sufficient. The default API base URL is `https://qwwapi.quotewerks.com`. Use your approved API endpoint, not the QuoteWerks browser sign-in page. The [QuoteWerks Web API reference](https://qwwapi.quotewerks.com/docs) is available for your administrator.

You need **manage_settings_integrations** permission to connect, test, save settings, sync, or delete the integration. Customer mapping and company creation have their own access requirements. Prefer existing portal companies when mapping; a new company is a separate portal record.

If you use QuoteValet, have a customer-facing quote link for the intended QuoteValet account ready. It is optional for quote synchronization. Keep API keys and private customer links out of screenshots and support messages.

## Connect QuoteWerks Web

<Steps>
  <Step title="Open the connection wizard">
    Open **Settings > Integrations**, find **QuoteWerks**, and select **Connect** for a new connection. For an existing connection, use its **Manage** or **Configure** action.
  </Step>
  <Step title="Enter the connection fields">
    In **Connect**, check **Base URL** and paste the raw key into **API Key**. Do not include a header name such as `X-API-Key:` or a `Bearer` prefix. The eye control shows or hides what you have entered.
  </Step>
  <Step title="Optionally add QuoteValet">
    Paste a valid customer-facing link for the intended account into **QuoteValet link**. This provides the account information needed to build links for quotes that have a QuoteValet document association. It does not create or publish a QuoteValet document.
  </Step>
  <Step title="Test the connection">
    Select **Test Connection** and wait for the result. A successful test may show user, account, or table information. It verifies API access; it does not save the form or prove that quotes have imported.
  </Step>
  <Step title="Save the connection">
    Select **Connect QuoteWerks**. Wait for success before continuing. Saving tests the connection again, stores the connection settings, and starts a background customer sync for mapping. It does not start the quote import.
  </Step>
  <Step title="Map customers and start quotes">
    Open **Map**, follow [Map QuoteWerks customers](/user-guides/integrations/map-quotewerks-customers), and verify the relevant rows show **Saved**. Then continue to **Complete**.
  </Step>
</Steps>

## Start the quote import

1. In **Complete**, select **Start quote sync**.
2. Wait for the started message, then use **Open Quotes** or open **Quotes** later.
3. Allow the background job to finish. Check a known quote, its company, number, line items, and totals.
4. Use **Complete Setup** when finished.

**Complete Setup** leaves the wizard; it does not itself start the quote import. A ready message or a completed wizard step does not prove that every customer is mapped or every quote imported.

Active connections are scheduled to refresh customers daily and quotes every four hours. These are background schedules, not immediate delivery guarantees. A manual sync also does not guarantee every historical quote will be included. If an older quote remains absent, ask MSPortal support to investigate its import window rather than repeatedly assuming the request imported all history.

## Update credentials and QuoteValet settings

Open the saved connection and return to **Connect**. The saved API key is not displayed. Leaving **API Key** blank keeps the stored key; the eye control does not reveal that stored secret.

- To replace the key, enter the new key and select **Update credentials**.
- To save the base URL or optional QuoteValet link using the stored key, select **Save settings**.
- A blank QuoteValet input preserves an already configured link. It is not a remove-link control.
- Wait for success before changing steps. **Next** and the step headings do not save unsaved Connect fields.

Saving settings can contact QuoteWerks and request a customer sync even when the API key field is blank. It is not merely a local display preference. If multiple QuoteWerks connections are listed, ask MSPortal support to confirm the intended connection before changing credentials or adding another account.

## Remove the integration

Use **Delete** in the existing wizard footer and read the confirmation. **Cancel** keeps the connection; **Delete Integration** confirms removal. Removal deletes the MSPortal connection and its synchronized QuoteWerks data and attempts to remove the stored credential. It does not delete the original QuoteWerks quotes or the portal companies you mapped to.

Do not delete the integration to clear one incorrect customer mapping. Use the row-level mapping controls instead. Reconnecting a deleted integration requires credentials and another import.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does this connect QuoteWerks Desktop?">
    This integration uses QuoteWerks Web and its API. A Desktop installation alone is not sufficient; ask your QuoteWerks administrator about Web API access.
  </Accordion>
  <Accordion title="Which API base URL should I enter?">
    Use the approved QuoteWerks Web API endpoint. The default is https://qwwapi.quotewerks.com. Do not use the browser sign-in page as the API base URL.
  </Accordion>
  <Accordion title="Which QuoteWerks API permission is required?">
    The connection requires a QuoteWerks Web API key with MasterRights access. Ask your QuoteWerks administrator to supply an appropriate key.
  </Accordion>
  <Accordion title="Does Test Connection save my API key?">
    No. Test Connection checks API access without saving. Use Connect QuoteWerks, Update credentials, or Save settings to persist the intended change.
  </Accordion>
  <Accordion title="Does a successful test prove all quotes imported?">
    No. The test checks API access. Map customers, explicitly start quote sync, and inspect actual quote and line-item results.
  </Accordion>
  <Accordion title="Why is the saved API Key field blank?">
    The form does not display the stored API key. Leaving the field blank preserves it; the eye control only reveals text you enter now.
  </Accordion>
  <Accordion title="Does Next save changes on Connect?">
    No. Use Connect QuoteWerks, Update credentials, or Save settings and wait for success before switching steps. Unsaved Connect fields can be discarded when navigating away.
  </Accordion>
  <Accordion title="Does Save settings also request synchronization?">
    Yes. It tests and saves the connection and requests customer synchronization, even when using the stored key. Start quote sync separately in Complete.
  </Accordion>
  <Accordion title="Do I need QuoteValet to synchronize quotes?">
    No. QuoteValet configuration is optional and supports customer-facing document links. Quote headers and line items can synchronize without it.
  </Accordion>
  <Accordion title="Does leaving QuoteValet link blank remove its configuration?">
    No. A blank field preserves the existing QuoteValet configuration. The field is not a remove-link control.
  </Accordion>
  <Accordion title="Does Complete Setup start quote synchronization?">
    No. Use Start quote sync explicitly. Complete Setup leaves the wizard; a ready message does not prove import or mapping success.
  </Accordion>
  <Accordion title="Will a manual sync include all historical quotes?">
    Not necessarily. Historical import windows and provider data can limit results. Ask MSPortal support to investigate a missing older quote rather than assuming a manual request imported every year.
  </Accordion>
  <Accordion title="Can a Company administrator change QuoteWerks credentials?">
    No. Company users ask their MSP to manage the integration. The MSP also handles user permissions and company access.
  </Accordion>
  <Accordion title="Can I safely configure a second independent QuoteWerks account?">
    If you need multiple QuoteWerks accounts or see multiple connections, ask MSPortal support to confirm the intended connection before changing credentials. Do not assume another setup entry creates an independent account.
  </Accordion>
  <Accordion title="Does deleting the integration delete the quotes in QuoteWerks?">
    No. Removal affects the MSPortal connection and synchronized data, not the original provider quotes or mapped portal companies. A later reconnect requires another import.
  </Accordion>
</AccordionGroup>
