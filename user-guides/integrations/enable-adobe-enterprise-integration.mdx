Connect **Adobe Enterprise** using Adobe VIP Marketplace OAuth credentials to synchronize supported customers and subscriptions. This is not a generic Adobe personal-account or Creative Cloud user login.

## Before you start

This is an **MSP staff** task requiring integration-management permission and authorized vendor credentials. This provider is available only when enabled for your MSP tenant. If its setup page is unavailable, check availability with your MSPortal administrator. Company users do not configure this connection.

Prepare a **Client ID / API key** and **Client Secret** from an Adobe Developer Console project with **Commerce Partner API** access. Follow the [Adobe VIP Marketplace credential instructions](https://developer.adobe.com/vipmp/docs/authentication/oauth-credentials).

## Connect Adobe

1. Open **Settings > Integrations**, find **Adobe Enterprise**, and open setup.
2. Enter **Client ID / API key** and **Client Secret**.
3. Use **Test Connection** to check the credentials and inspect any error.
4. Choose **Connect** to store the new connection. Testing and saving are separate actions; the save does not depend on first clicking the test button.

For an existing connection, enter the replacement values and choose **Update**. Blank unchanged fields preserve stored credentials. If an older connection has no Client Secret, supply it before continuing. Testing an existing connection can use its stored values without displaying them.

## Map customers to companies

The wizard continues through **Map companies** and **Finish**. Review the returned Adobe customers and choose the intended MSPortal companies. Review **Quick Match** suggestions before applying them.

Company selections remain pending until submitted. Check the selected imports and pending links before choosing **Import Selected**; wizard navigation also attempts to save pending mappings. Creating a new company is immediate; removing an already saved link is immediate. Do not confuse either with discarding a draft suggestion.

## Synchronize and review licenses

On **Finish**, use **Sync All Data** when you intend to request a fresh sync. Wait for the actual result and check the connection’s latest customer/subscription sync status. A **Sync started** message only acknowledges the request.

Review the resulting company-scoped licensing information after synchronization and mapping complete. This setup imports customer/subscription reporting; it does not itself purchase seats, place orders or assign applications to end users. Storefront purchasing, where separately supported and enabled, is a different workflow.

## Disconnect

Use the connection’s delete/disconnect control and read the named confirmation. Removing the connection also removes associated synchronized Adobe data and company mappings. It does not revoke the Adobe Developer Console credentials.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| Test fails | Correct Commerce Partner API project, credential pair and provider error. |
| Old connection cannot continue | Supply its missing Client Secret; a previously saved API key alone is insufficient. |
| No customers or subscriptions | Provider access, completed discovery, saved company links and the latest sync result. |
| Credential update did not persist | Use **Update**; testing alone is not a save. |
| Licenses are shown for the wrong company | Recheck the saved Adobe customer mapping before relying on the report. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I connect using an Adobe personal account password?">
    No. This integration uses VIP Marketplace OAuth credentials from a project with Commerce Partner API access.
  </Accordion>
  <Accordion title="Does Test Connection save credentials?">
    No. Use **Connect** or **Update** for persistence.
  </Accordion>
  <Accordion title="Does connecting Adobe purchase licenses?">
    No. This setup connects customer/subscription synchronization. Purchasing is a separate supported workflow.
  </Accordion>
  <Accordion title="Does Sync started mean all subscriptions are available?">
    No. Check the completed sync result and saved company mappings.
  </Accordion>
  <Accordion title="What happens when I disconnect?">
    The MSPortal connection, stored credentials, synchronized Adobe data and mappings are removed. Vendor-side credential revocation is separate.
  </Accordion>
</AccordionGroup>
