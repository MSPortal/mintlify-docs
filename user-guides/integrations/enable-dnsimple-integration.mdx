DNSimple brings domain inventory and renewal information into MSPortal. This setup is for **MSP staff with integration management access**. Company users use the domain information their IT provider makes available; they do not configure this connection.

## Before you connect

Use an account API token for the DNSimple account that owns the domains. Follow [DNSimple’s current token instructions](https://support.dnsimple.com/articles/api-access-token/): open the account’s **API & Access** page and generate an account token. The MSPortal form may still call this **Account → Access Tokens**. Copy the token securely when it is shown. The wizard uses the production DNSimple service.

## Connect and save

1. Open **Settings > Integrations**, find **DNSimple**, and open its setup.
2. On **Connect**, enter the **Account API Token**.
3. Use **Test connection** to check the entered token. A successful test does not save a new integration.
4. Choose **Save and connect**. This checks the token again, saves the connection, and requests an initial background domain sync.
5. After saving succeeds, choose **Next** to open **Map**. There is no guaranteed completion time for the background import.

## Map domains to existing companies

Wait for imported domains to appear. If the empty mapping view offers **Sync Domains**, use it to request an inventory sync, then allow time for results.

Choose an existing company for each domain, or use **Quick Match** and review its suggestions before applying them. These choices are pending links. **Import Selected** applies pending links; **Next** also attempts to save pending changes before leaving Map and requests another sync. Review all pending links before applying: a table filter does not make unrelated pending choices disappear.

DNSimple mapping does **not** create companies from domain names. Create the company separately if it is missing. Removing a saved mapping is immediate; clearing an unsaved suggestion only clears that pending choice.

Where available, **Ignore** removes an unmapped domain from the mapping backlog, and **Restore** brings it back. Both save immediately. Remove an existing or pending company link before ignoring a domain. Ignoring is a mapping decision, not a domain deletion or a DNS change.

## Complete and check results

On **Complete**, **Run full sync** requests a background inventory refresh. A successful request or **All set** message is not proof that every domain is imported or mapped. **Complete setup** finishes the wizard; it does not wait for the sync to finish.

The configured daily refresh is 06:30 UTC. Actual execution and freshness depend on a working connection and successful background runs. Sync reconciles domains removed from the DNSimple account as well as current domains. Review the resulting inventory and company links after an account change or transfer.

Open **Map companies** from Integrations to revisit links. Use [Cloud Domains](/user-guides/cloud/domains) to read available domain information and [domain renewals](/user-guides/cloud/review-domain-renewals) for interpretation. Hosted DNS-only domains may lack registration expiry information. Missing expiry is not a successful renewal check.

## Update or remove the connection

Reopen setup and return to **Connect**. Leaving the token blank retains the saved token. **Test connection** with a blank field tests that saved token. To rotate it, enter the replacement, test it, and choose **Update credentials**. **Next** is not a credential save.

Use a replacement token for the same account when rotating credentials. A token for another account changes the inventory being synchronized; review that change deliberately rather than treating it as a routine rotation.

**Delete** opens a confirmation to remove the MSPortal connection. This does not delete domains or DNS records in DNSimple. Review downstream use of imported data before disconnecting.

## Troubleshooting

- **Test fails:** check the account, token validity and token access. Do not paste credentials into support screenshots.
- **Connected but empty:** connection save and domain sync are separate results. Check the sync outcome and account before repeatedly reconnecting.
- **Wrong company:** correct the mapping, apply it, then check the updated domain view.
- **Old domain remains:** allow a successful full inventory refresh; a sync-start toast alone is insufficient.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Test connection save DNSimple?">
    No. Use Save and connect for a new connection or Update credentials for a replacement token.
  </Accordion>
  <Accordion title="Does Save and connect open Map automatically?">
    After the save succeeds, choose Next. The initial sync runs separately in the background.
  </Accordion>
  <Accordion title="Can a DNSimple domain create a company?">
    No. This mapping workflow links domains to existing companies.
  </Accordion>
  <Accordion title="When do domain mappings save?">
    Import Selected applies pending links; Next attempts to save pending changes before leaving Map. Removing a saved link is immediate.
  </Accordion>
  <Accordion title="Does Ignore delete a domain?">
    No. It immediately hides an unmapped domain from the mapping backlog. Restore reverses that choice.
  </Accordion>
  <Accordion title="Does Complete setup prove synchronization finished?">
    No. Check the resulting inventory and mappings; completion and sync-start messages do not establish background success.
  </Accordion>
  <Accordion title="How do I rotate the DNSimple token?">
    Enter and test the new token, then use Update credentials. A blank field retains the saved token; Next does not save a typed replacement.
  </Accordion>
</AccordionGroup>
