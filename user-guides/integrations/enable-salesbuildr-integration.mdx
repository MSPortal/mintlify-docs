Connect **Salesbuildr** through **Settings > Integrations**. The setup wizard has **Connect**, **Map**, and **Complete** steps. Salesbuildr supplies company records for mapping, quotes and line items for mapped companies, and products that MSP staff can import into their budget catalog.

**Audience:** MSP staff with integration-management permission. Company users read permitted quotes and documents; their MSP manages connections, company mappings, and user access.

## Before you start

Salesbuildr is available as a beta integration for enabled MSPortal accounts. If the card is unavailable, ask MSPortal support about availability. You need **manage_settings_integrations** permission to test, connect, save credentials, sync, or remove it. Mapping and creating portal companies have separate permissions.

Your Salesbuildr account must have its **Public API** feature enabled. A Salesbuildr administrator can generate a key under **Settings > Integrations > API Key**. Obtain the key and your account address from that administrator. See [Salesbuildr Public API guidance](https://help.salesbuildr.com/articles/3446453-public-api).

Use the account's `.salesbuildr.com` address, such as `https://example.salesbuildr.com`. A custom customer quote-portal domain is not accepted for this connection. Do not add a username, password, or port to the URL. A pasted path, query, or fragment is discarded; MSPortal saves the HTTPS account address.

## Connect the account

<Steps>
  <Step title="Find Salesbuildr">
    Open **Settings > Integrations**, find **Salesbuildr**, and select **Connect** for a new connection. Use **Manage** or **Configure** to open an existing connection.
  </Step>
  <Step title="Enter the two fields">
    Enter **Account URL** and paste the raw **API key**. Do not include an `api-key:` header prefix. Both fields need values before a new connection can be tested or saved. Keep the key out of screenshots and support messages.
  </Step>
  <Step title="Test API access">
    Select **Test Connection**. Wait for a success or error result. The result can include a company count, but that count is not the number of companies mapped or quotes imported. This button does not save credentials.
  </Step>
  <Step title="Save the connection">
    Select **Connect Salesbuildr** and wait for success. This tests the connection again, saves its credentials and account address, and requests a background company import. If that import cannot start, the saved connection can still exist; check Map rather than submitting another new connection immediately.
  </Step>
  <Step title="Map the companies">
    Open **Map** and follow [Map Salesbuildr companies](/user-guides/integrations/map-salesbuildr-companies). Verify the intended links show **Saved** before relying on them.
  </Step>
</Steps>

## Start and verify quote synchronization

After saving mappings, **Next** from Map requests quote synchronization. The Salesbuildr wizard also attempts to save pending mapping work when you use a step heading to leave Map, then requests a quote sync. **Complete Setup** requests quote synchronization before leaving the wizard. This differs from the Quoter and QuoteWerks setup workflows.

For an explicit request, use **Complete > Start quote sync**. Wait for the started message and use **Open Quotes**. A started message confirms the request, not successful import of every quote or line item. Check a known quote's company, number, status, line items, totals, and available document.

If a sync is refused because the integration is paused, the mapping can remain saved even though no sync started. Review the integration's status and error, repair its connection, and request another sync after it is active.

## Know which data is refreshed

| Data | Background schedule | What to verify |
| --- | --- | --- |
| Companies | Daily; also requested after connection saves and by Map > Sync | Imported source records available for mapping. Supplier, manufacturer, vendor, and distributor types are excluded. |
| Quotes and line items | Every four hours; also requested after mapping navigation or explicitly in Complete | Only companies with saved portal mappings are eligible. Check actual quote and line-item results. |
| Products | Daily; also included in the integration card's **Refresh** action | Synchronized source products can be imported or linked into the budget catalog. |

Schedules are not immediate delivery guarantees. A stale provider quote can remain visible when an import is empty or fails. Verify the current provider document when freshness matters; do not assume every deletion is reflected by the next attempted run.

## Update the account or credentials

Open the saved connection's **Connect** step. Its API key input is blank because stored credentials are not displayed. The eye control only reveals text you enter now.

1. Check the intended connection and **Account URL**.
2. Enter a replacement key if needed, then use **Update credentials**. Leaving the key blank retains the stored key and shows **Save settings** instead.
3. Wait for success. Saving validates the connection, reactivates it, and requests a company import.
4. Reopen the saved connection from the integration list to verify the account address, then review mappings and quote results.

**Test Connection**, **Next**, and step navigation do not save unsaved Connect fields. Use the connection's save button first. Changing the account address affects API access and quote links; use the address for the account whose data belongs to that connection.

If an existing connection unexpectedly opens as a blank new-connection form, return to the integration list and check its status or ask support before submitting. A load failure should not be treated as proof that the connection no longer exists.

## Use Salesbuildr products in budgets

Company synchronization and quote synchronization do not import products into your budget catalog. After product synchronization finishes, open **Budgets > Budgets Menu > Products > Import from Integrations**. Select source products to create catalog records or link them to existing ones.

Follow [Import and link budget products](/user-guides/budgets/import-products-from-integrations) for selection, save, and retry behavior. Linking an existing product does not replace its price or recurrence. Verify imported pricing and billing cadence before adding products to a budget; synchronization alone does not update every existing budget line.

## Remove the integration

Use **Delete** in the saved wizard and read the confirmation. **Cancel** keeps the connection. **Delete Integration** removes the MSPortal connection and its synchronized Salesbuildr data and attempts to remove stored credentials. It does not delete the original data in Salesbuildr or the portal companies you mapped to.

Removal is separate from correcting one mapping or repairing an API key. A later connection requires credentials, mapping review, and new synchronization.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What do I need before connecting Salesbuildr?">
    You need the integration enabled for your MSPortal account, integration-management permission, a Salesbuildr account with Public API access enabled, its API key, and its salesbuildr.com account address.
  </Accordion>
  <Accordion title="Where can a Salesbuildr administrator create an API key?">
    In Salesbuildr, open Settings > Integrations > API Key. The Public API feature must be enabled and the user must have the Admin role. See the linked Salesbuildr Public API guidance.
  </Accordion>
  <Accordion title="Can I enter a custom quote-portal domain as Account URL?">
    No. Use the account address ending in .salesbuildr.com. A custom quote-portal domain is not accepted for the API connection.
  </Accordion>
  <Accordion title="Does Test Connection save credentials?">
    No. It tests API access. Connect Salesbuildr, Update credentials, or Save settings performs the save and requests a company import.
  </Accordion>
  <Accordion title="Does the company count mean those companies are mapped?">
    No. A connection-test count reflects the provider response, not saved portal mappings or imported quotes. Review Map and actual Quotes results separately.
  </Accordion>
  <Accordion title="Why is the stored API key not visible?">
    The input does not display the stored key. Leaving it blank preserves that key on an existing connection. The eye control shows only the text you enter now.
  </Accordion>
  <Accordion title="Does Next save my edited Account URL?">
    No. Save Connect fields with Save settings or Update credentials before navigating. Reopen the saved connection from the integration list to verify the stored account address.
  </Accordion>
  <Accordion title="Does Complete Setup start a Salesbuildr quote sync?">
    It requests quote synchronization before leaving the Salesbuildr wizard. Unlike Quoter and QuoteWerks, Salesbuildr also requests quote sync after leaving Map through Next or a step heading. A request does not prove import completion.
  </Accordion>
  <Accordion title="Does connecting Salesbuildr import every quote?">
    No. Connection saving requests companies for mapping. Quotes are eligible only for saved mapped companies and need a quote sync. Check actual results after the background job finishes.
  </Accordion>
  <Accordion title="Can a Company user repair a paused integration?">
    No. The MSP reviews the integration status and credentials. Saving a working Salesbuildr connection reactivates it and requests companies; verify the subsequent quote sync separately.
  </Accordion>
  <Accordion title="Does importing Salesbuildr products automatically update existing budget lines?">
    No. Source synchronization, catalog import or linking, and budget line editing are separate workflows. Review product prices and recurrence and follow the budget-product guides.
  </Accordion>
  <Accordion title="Why are supplier or manufacturer records absent from Map?">
    Salesbuildr supplier, manufacturer, vendor, and distributor company types are excluded from the source mapping list. Check the source record type with your Salesbuildr administrator.
  </Accordion>
  <Accordion title="Why did an existing connection open as a blank setup form?">
    The saved connection may have failed to load. Return to the integration list and check its status or ask support before creating another connection; a blank form does not prove the old connection was deleted.
  </Accordion>
  <Accordion title="Does deleting the integration delete the original Salesbuildr data?">
    No. Deletion removes the MSPortal connection and synchronized data. Original Salesbuildr records and the portal companies you mapped to are separate.
  </Accordion>
</AccordionGroup>
