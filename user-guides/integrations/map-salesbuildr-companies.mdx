Use **Salesbuildr setup > Map** to link an imported Salesbuildr company to the correct MSPortal company. Salesbuildr quotes are imported only for mapped companies. Mapping is separate from each Company user's permission to see those quotes.

**Audience:** MSP staff with integration-company mapping access. Company users ask their MSP to correct company links or quote permissions. Creating a new portal company requires company-write access and active billing.

## Find and map a company

1. Open **Settings > Integrations**, manage the saved **Salesbuildr** connection, and select **Map**.
2. Wait for the table. Use **Name** and **Mapped** filters to find the source company; the **Type** column helps identify the provider record.
3. If the source company is missing, select **Sync** to request a company import. Allow it to finish and check for connection errors.
4. Choose the intended existing portal company from the row's company selector. The selection shows **Pending**.
5. Clear unrelated checkbox selections, then select **Import Selected**. Verify the intended row shows **Saved**.
6. Continue with **Next** and allow the requested quote synchronization to finish. Check a known quote under the intended company.

The **Mapped** count can include pending choices. A changed count or a completed wizard step is not proof that the link persisted. Use the row's status and the saved mapping when reopened.

## Assign several source companies to one portal company

Select only the intended source rows, choose an existing company in the bulk selector, and select **Assign**. This stages **Pending** mappings and clears the row selection. Review each target company, select **Import Selected**, and verify **Saved**.

You can link several source companies to one portal company. Confirm their quotes should be visible under that portal company before combining them.

## Use Quick Match

Select **Quick Match**, review the proposed source-company and portal-company pairs, and adjust the confidence threshold and selected proposals. Review identities rather than trusting a name score alone. A filtered search can hide proposals that are still selected, so review the complete selected set before applying.

Applying proposals leaves **Pending** links. Select **Import Selected** and verify **Saved** before relying on them. Quick Match does not itself import quotes.

## Create a portal company when one does not exist

Prefer choosing an existing company. The row's add-company control opens **Create Company** when you need a separate portal record. Submitting creates the company immediately, then leaves its mapping pending. Clearing that mapping does not delete the newly created company.

<Warning>
**Import Selected** can create portal companies for selected unmapped rows, as well as save pending mappings. If you intend to reuse existing companies, choose them first with the row selector or bulk Assign. Clear unrelated selections before saving.
</Warning>

## Remove or correct a saved mapping

The **×** beside a **Pending** choice clears the unsaved choice. The **×** beside a **Saved** link immediately unlinks the company without another save or confirmation.

<Warning>
Unlinking a Salesbuildr company removes its imported quotes and their line items from MSPortal. It does not merely leave unassigned quote rows, as QuoteWerks does. The original Salesbuildr quotes and the portal company are not deleted.
</Warning>

To correct the company using this row control, clear the incorrect saved link, select the correct existing company, and save with **Import Selected**. Then request quote synchronization and verify the quotes reappear under the correct company. Saving a new link alone cannot restore imported rows already removed by unlinking.

If a batch reports an error, some changes may already be saved. Reopen the mapping table, review which rows show Saved, and retry only what remains. Do not assume the entire batch rolled back.

## Navigate without losing track of saves

Salesbuildr's **Next** and step headings attempt to save pending Map work before leaving and request quote synchronization. **Complete Setup** also requests quote synchronization. Review errors and verify Saved rather than treating navigation or a ready message as proof of success.

The footer **Back** does not use the same pending-save flow. Save explicitly before using it. Changes to the Connect form are separate: use **Save settings** or **Update credentials** before leaving Connect.

A paused integration can retain saved mappings while synchronization is refused. Ask an MSP administrator to restore the connection, then request the quote import again.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I map Salesbuildr companies?">
    MSP staff open Settings > Integrations, manage Salesbuildr, and select Map. Company users ask their MSP to correct the company assignment.
  </Accordion>
  <Accordion title="Does selecting a portal company immediately save it?">
    No. It creates a Pending choice. Use Import Selected and verify Saved before relying on the link.
  </Accordion>
  <Accordion title="Does bulk Assign save mappings?">
    No. Assign stages pending choices and clears row selection. Review them, then use Import Selected and verify Saved.
  </Accordion>
  <Accordion title="Can Import Selected create new companies?">
    Yes. Selected unmapped source rows can create portal companies. Choose existing companies first and clear unrelated selections if you only want to save mappings.
  </Accordion>
  <Accordion title="Does Quick Match import quotes?">
    No. Applying suggestions stages mappings. Save them, then request quote synchronization and verify the actual quote results.
  </Accordion>
  <Accordion title="Does clearing a Pending choice delete the company I just created?">
    No. Company creation is an immediate separate write. Clearing a pending mapping does not remove that portal company.
  </Accordion>
  <Accordion title="What does the × beside a Saved Salesbuildr link do?">
    It immediately removes the saved company link and the related imported Salesbuildr quotes and line items, without another save or confirmation. Original provider quotes and the portal company remain.
  </Accordion>
  <Accordion title="Is Salesbuildr unlinking the same as QuoteWerks unlinking?">
    No. Salesbuildr removes the related imported quotes when unlinked. QuoteWerks can retain imported quotes without a company assignment. Follow the guide for the actual provider.
  </Accordion>
  <Accordion title="Will relinking restore quotes deleted by unlinking?">
    Relinking makes the company eligible for another quote import. Request quote synchronization and verify the records reappear; saving the new link alone does not restore removed rows.
  </Accordion>
  <Accordion title="Does Complete prove all Salesbuildr mappings saved?">
    No. Navigation attempts saving and may request sync, but errors or partial changes are possible. Reopen the table and verify each intended row shows Saved.
  </Accordion>
  <Accordion title="Does Back save pending Map work?">
    The footer Back does not use the same pending-save flow as Next and step headings. Save explicitly with Import Selected before using Back.
  </Accordion>
  <Accordion title="Can mappings be saved while synchronization is paused?">
    Saved mappings can remain even when synchronization is refused for an inactive integration. Repair the connection and request the import again.
  </Accordion>
  <Accordion title="Why did only part of my mapping batch save?">
    Mapping operations can fail after other rows have saved. Reopen Map and inspect the actual saved rows before retrying; do not assume a full rollback.
  </Accordion>
</AccordionGroup>
