Connect **N-able N-central** to bring its customers and device inventory into MSPortal. The setup flow is **Connect → Map → Import**.

## Before you start

This is an **MSP staff** task. You need access to **Settings > Integrations**, permission to manage integrations, authorized vendor credentials, and companies to receive the imported records. Company users do not configure this connection.

Create or use an API user with access to the intended customers. In N-central, open **Administration > User Management > Users**, select that user, then **API Access > Generate JSON Web Token**. Follow the current [N-able token instructions](https://developer.n-able.com/n-central/reference/authenticate) for API-user requirements.

## Connect the provider

1. Open **Settings > Integrations**, find **N-able N-central**, and choose its connection/setup action. Use **Configure** on the existing connection when managing an established setup.
2. Enter the connection fields below.
3. Choose **Test Connection** and resolve any reported error.
4. After a successful test, choose **Create Integration**. This saves the connection and starts discovery. A successful test alone does not create it.

| Field | What to enter |
| --- | --- |
| **Server URL** | The HTTPS root address of your N-central server. |
| **API Token (JWT)** | The User-API token generated for the authorized N-central user. |

N-central availability is controlled for your MSP tenant. If it is absent from the integrations catalog, ask your MSPortal administrator about availability. An unavailable setup page is not evidence of invalid vendor credentials.

<Note>N-central setup is available only for enabled MSP tenants. The field names above describe that setup; contact your administrator if the page is unavailable.</Note>

## Map customers to companies

1. Continue to **Map** after discovery has returned the provider’s customers.
2. Select an existing company for each intended record, or use **Quick Match** and review each suggested company.
3. Review the pending links, then choose **Import Selected** to apply the selected imports and pending links. Check the selected records as well as the pending-link count before submitting. The wizard’s **Next** also attempts to save pending mappings before continuing. Check that the rows show saved links before proceeding.
4. Remove a pending suggestion to discard that draft. Removing an already saved link takes effect immediately.

Creating a company from the mapping screen creates the company immediately; its new mapping still needs to be saved. Check for an existing company first to avoid duplicates. Moving forward from mapping can start synchronization using the saved links.

## Import devices

The **Import** step is an entry point. Select **Open Device Import** to open the actual device staging and type-mapping page.

Review the company and device type before importing. Map provider categories to MSPortal device types, then import the intended records. Where offered, **Auto-Sync** enables future imports for the mapped category and **Ignore** excludes a category. These are saved configuration choices, not temporary list filters.

Follow [Import Devices](/user-guides/integrations/import-devices) for selection, type mappings and result handling. Check the import result and resulting Devices records. **Complete Setup** finishes the wizard; its success message does not prove every background sync or device import has completed.

## Manage an existing connection

Reopen the existing connection to change Server URL or API Token. Test the revised values, then choose **Update API Key** to save them; that label also applies to this JWT-based connection. Retesting alone does not save a replacement.

Reopen the specific connection to review mappings and imports. An existing **Connection verified** state is not evidence that a fresh retest just ran. Inspect recent sync status and errors when diagnosing stale inventory.

The wizard’s **Delete** action opens a **Delete Integration** confirmation. Read it before proceeding: deletion is not a refresh or a temporary pause. It does not revoke vendor credentials on the vendor’s behalf.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| Connection test fails | Credential type, vendor access, host/region, expired or revoked credentials, and the reported error. |
| Map is empty | Discovery status and the vendor account’s access to the intended records. Avoid repeatedly creating connections. |
| A mapping disappeared | Check whether it was pending or saved. Reopen the connection to verify the saved state. |
| Devices are missing | Saved company mappings, completed device sync, type mappings, Ignore settings and the import result. |
| Inventory is old | Last successful provider sync, any paused state, and connection errors. A scheduled time does not guarantee a successful run. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Test Connection save the integration?">
    No. For a new connection, complete the successful test and then choose **Create Integration**. Existing-connection retesting is also distinct from any credential-update action.
  </Accordion>
  <Accordion title="Does Quick Match immediately save every suggested link?">
    No. Review and apply the intended suggestions, then save the pending mappings. Removing a saved link is an immediate change.
  </Accordion>
  <Accordion title="Does Complete Setup mean all devices are imported?">
    No. Device discovery, saved mappings and inventory imports have separate results. Open the device import page and check the resulting inventory.
  </Accordion>
  <Accordion title="Can a Company user configure this provider?">
    No. Provider setup is an MSP settings task. Company access to resulting data depends on portal permissions and company scope.
  </Accordion>
  <Accordion title="Why are customers visible but devices missing?">
    Customer discovery, company mapping, device synchronization and inventory import are separate stages. Check the saved customer mapping and device sync result before importing.
  </Accordion>
</AccordionGroup>
