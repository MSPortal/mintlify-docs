Documentation brings together resources your MSP makes available to you. It supports native portal pages and files, shared provider records, and an optional resource hub. Your role, company scope, and the MSP's sharing settings determine what appears.

## Available tabs

| Tab | Purpose | Availability |
| --- | --- | --- |
| Hub | Curated documents, folders, and links | Enabled by the MSP; it can also appear as a separate page or replace Overview |
| Documents | Portal pages, uploaded files, and shared articles | Documentation access; native content does not require a provider |
| Assets | Shared documentation asset records | Hudu or IT Glue and documentation access |
| Configurations | IT Glue configuration inventory | IT Glue and documentation access |
| Passwords | Credentials shared with your role and company | Supported documentation provider, password sharing enabled, and password permission |
| Procedures | Provider runbooks and recorded task status | Supported documentation provider and documentation access |
| Inspectors | Shared Liongard service and environment records | Liongard and documentation access |
| Domains | Company domain inventory | Domain-documentation permission |

## FAQs

<AccordionGroup>
  <Accordion title="Why does my Documentation page have fewer tabs?">
    Tabs depend on provider connections, sharing settings, and your permissions. Ask your MSP about the specific resource you need.
  </Accordion>
  <Accordion title="Does documentation access include passwords?">
    No. Passwords require separate permission and provider-sharing configuration.
  </Accordion>
  <Accordion title="Can Company users manage the document library?">
    The MSP manages native pages, uploads, folders, and sharing rules. Company users access content made available to them.
  </Accordion>
  <Accordion title="How can I get an incorrect document updated?">
    Give your MSP the document title, selected company, and the information that needs correction. Provider records may need to be changed in Hudu, IT Glue, or Liongard.
  </Accordion>
</AccordionGroup>
