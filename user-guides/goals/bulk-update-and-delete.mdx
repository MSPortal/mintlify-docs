**Audience:** MSP staff or Company users explicitly granted Goals management permission. Reading Goals alone does not enable selection or bulk changes.

## Change several goals

1. Open **Goals** and check the company scope and filters.
2. Select the intended goals with their checkboxes. The header checkbox selects the current page, not every goal in the organization.
3. Check the selected count in the header’s **Actions** menu.
4. Choose **Set Status**, **Set Priority**, or **Set Category**, then the desired option. **None** under Set Category clears the category.
5. Wait for the success message and refreshed list. Recheck affected records.

Selecting a bulk status, priority, or category option applies the change immediately; there is no second Save form. Changing status does not update progress. Filtering the table removes selections that no longer match the filtered result. Changing company scope clears the workspace selection.

## Delete one goal

1. Open its row menu and select **Delete Goal**.
2. Read the confirmation, including the goal title.
3. Select **Delete Goal** in the confirmation only if this is the intended record.
4. Wait for the result and verify the list.

## Delete several goals

1. Select the intended rows and check the selected count.
2. Open **Actions > Delete Selected**.
3. Review the confirmation and select **Delete Goals**.
4. Wait for success and verify the remaining list.

<Warning>
There is no undo or restore action in this Goals interface. Keep a goal and change its status when you need to preserve the record instead of deleting it.
</Warning>

Bulk changes are checked against every requested goal’s access and options. If the operation fails, do not assume a success from the selection disappearing; inspect the result and error. Bulk status, priority, category, and delete operations support at most 1,000 selected goal IDs per request.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Select all mean every goal in my tenant?">
    No. The table header checkbox selects the current page. Confirm the selected count and company scope.
  </Accordion>
  <Accordion title="Do bulk field changes ask for confirmation?">
    Status, priority, and category choices apply immediately. Deletion has a separate confirmation dialog.
  </Accordion>
  <Accordion title="Can I bulk-update progress?">
    The Goals Actions menu provides status, priority, and category changes. Edit an individual goal to change progress.
  </Accordion>
  <Accordion title="Can I undo a deletion here?">
    There is no undo or restore control in this interface. Verify the record or count before confirming.
  </Accordion>
  <Accordion title="Can I use the selected checkboxes to export only those goals?">
    No. **Export CSV** uses the filtered list. See [Find and read goals](/user-guides/goals/read-goals).
  </Accordion>
</AccordionGroup>
