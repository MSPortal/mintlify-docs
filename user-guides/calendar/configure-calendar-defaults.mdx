**Audience:** MSP administrators with Calendar settings access and permission to manage Calendar settings. Company users can [read and filter the Calendar](/user-guides/calendar/filter-calendar-events); they do not change these tenant settings.

Open **Settings > Calendar > General Settings**. These defaults apply across your MSP tenant. They are separate from the current viewer's filters and the [Freeze Windows](/user-guides/calendar/manage-freeze-windows) and [Post-Meeting](/user-guides/calendar/configure-post-meeting) tabs.

## Change general defaults

<Steps>
  <Step title="Choose busy-block labels">
    **Show event details** displays an available subject instead of a generic Busy label for calendar busy blocks. Access restrictions and missing subjects can still limit the details shown. This is not a setting for every meeting, file or private note.
  </Step>
  <Step title="Set the default meeting length">
    Choose **Default Meeting Duration**: **15 minutes**, **30 minutes**, **45 minutes**, **1 hour**, **1.5 hours** or **2 hours**. It provides a starting length for new Calendar meeting drafts. Review each draft before saving it.
  </Step>
  <Step title="Choose the start of the week">
    Set **Week Start Day** to **Sunday** or **Monday**. This affects calendar week layout and date ranges. It does not move existing meetings to another date.
  </Step>
  <Step title="Save">
    Select **Save** in the page header and wait for completion. Switching tabs does not save the draft; unsaved changes can remain when you return to General Settings. Reopen the page to verify the saved values.
  </Step>
</Steps>

Changing these defaults does not rewrite existing meeting start/end times, send invitations or change Microsoft/PSA synchronization settings.

## Set Regular Hours and half-day ranges

In **Work Hours**, edit the Start and End clock fields for each range. Check the hour, minutes and any AM/PM segment shown by your browser.

| Range | Used by |
| --- | --- |
| **Regular Hours** | The meeting editor's full-day duration shortcut. |
| **Morning** under **Half Day Settings** | The morning half-day shortcut. |
| **Afternoon** under **Half Day Settings** | The afternoon half-day shortcut. |

<Frame caption="MSP example: Regular Hours set to 8 AM–5 PM. Your MSP can choose different defaults.">
  <img src="/images/product/calendar-regular-hours.png" alt="Regular Hours showing Start at 8 AM and End at 5 PM" width="772" height="260" />
</Frame>

Each range must end later than it starts on the same day. An overnight range such as 10 PM–6 AM is not accepted here. The form disables Save for an invalid range and displays **Enter valid start and end times, with the end after the start.**

These are clock-time defaults, not a time-zone selector or a rule that prevents meetings outside office hours. Check the Calendar time zone and the final meeting dates/times before saving a draft. A full-day or half-day label uses your configured range; do not assume it always means exactly eight or four elapsed hours.

Select the header **Save** after editing the ranges. Reload to discard unsaved changes and return to the saved defaults.

## Troubleshooting

- **Save is disabled:** there may be no changes, a save may be in progress, or a Start/End range may be invalid.
- **Save fails despite opening the page:** viewing settings and managing them are separate permissions. Ask an MSP administrator to check your role.
- **Busy is still shown:** check whether a subject is available, the saved Show event details setting and your access. [Calendar Blocks visibility](/user-guides/calendar/filter-calendar-events) is a separate control.
- **Existing meetings did not change length:** defaults affect new drafts and explicit duration choices, not previously saved meetings.
- **I need calendar synchronization settings:** use the appropriate [integration guide](/user-guides/integrations/index). General Settings does not connect a provider calendar.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I change Calendar defaults and work hours?">Open Settings, Calendar, General Settings. Edit the general controls or Work Hours and select Save in the page header.</Accordion>
  <Accordion title="Can Company administrators change these Calendar defaults?">No. These are MSP tenant settings. Company users can use the calendar views and filters their MSP makes available.</Accordion>
  <Accordion title="Are General Settings personal calendar preferences?">No. These settings apply across the MSP tenant. A viewer's current calendar filters are separate.</Accordion>
  <Accordion title="Which default meeting durations can I select?">Choose 15, 30 or 45 minutes, 1 hour, 1.5 hours or 2 hours. Check the actual new draft before saving it.</Accordion>
  <Accordion title="Does changing the default duration resize existing meetings?">No. It changes the starting length of new Calendar meeting drafts. Existing meetings keep their saved dates and times.</Accordion>
  <Accordion title="Can I start the calendar week on Monday?">Yes. Set Week Start Day to Monday and save. Sunday is the other available choice.</Accordion>
  <Accordion title="What does Show event details change?">It uses an available subject instead of a generic Busy label for calendar busy blocks. Missing data and access restrictions still apply; it does not configure all private content.</Accordion>
  <Accordion title="Do Work Hours block meetings outside those hours?">No. They provide full-day and half-day time defaults. Review scheduling and restrictions separately.</Accordion>
  <Accordion title="Can I save work hours that run overnight?">Not in these same-day ranges. Every End must be later than its Start. An overnight range such as 10 PM–6 AM is invalid here.</Accordion>
  <Accordion title="Do the full-day and half-day shortcuts always mean eight and four hours?">No. They use the configured Regular Hours, Morning or Afternoon time range. Review the final draft start and end times.</Accordion>
  <Accordion title="Does switching settings tabs save General Settings?">No. Unsaved changes can remain when you return to the tab. Use the header Save explicitly; reload to discard unsaved changes.</Accordion>
  <Accordion title="Does saving General Settings send invitations or change provider synchronization?">No. It saves Calendar defaults. Invitation sending and provider integration configuration are separate workflows.</Accordion>
</AccordionGroup>
