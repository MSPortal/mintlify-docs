**Audience:** MSP staff and other users explicitly permitted to create Planner work from Security. Security read access alone is insufficient. Company users should ask their MSP when the action is unavailable.

## Prepare a same-company selection

1. Open **Security > Compliance** or **Security > Vulnerabilities**. A similar shortcut is available for supported Cork endpoint rows.
2. Select the company, then check the rows you want to group.
3. Select **Add to Planner** from the page's bulk-actions menu.
4. Verify the source items and company in the draft before saving.

All selected items must belong to the same company. Work from the visible loaded page and verify the draft's actual source list; a selection count alone does not prove that records from other pages are included. For an unmapped record, ask the MSP to correct mapping before relying on the shortcut.

Several findings create **one** Planner item with source links. This is not one Planner item per row, and it does not remove or resolve the original findings.

## Review and save

The draft contains a title, summary description, and technical details in Private Notes. An At Risk event gives the draft High business value. Critical or Accelerated vulnerabilities also give High business value; other findings normally start at Medium. These defaults can be reviewed before saving.

Choose the required item type and review the title, description, status, business value, due date, estimates, and notes. The initial due date is today, so replace it when another date is appropriate. Select **Save**, wait for the result, then open the new item in Planner and verify its source links and saved values.

Opening the draft does not save it. Saving the Planner item and attaching the Cork links are separate steps. If an error occurs, check Planner before retrying: an item may already exist with only some links attached.

<Warning>
The current Cork shortcut does not reliably carry every option in the shared Planner form into the saved item. In particular, do not rely on **Hide from Company users** in this shortcut to keep the resulting item private. Avoid confidential titles, descriptions, or public notes here. Verify sharing through the main Planner workflow before adding information that requires restricted visibility.
</Warning>

Other advanced values, including assignment, start/end dates, cost details, and custom fields, require verification in the saved Planner item. The draft can expose more controls than this shortcut currently persists. Do not assume that closing the dialog proves every value and link was saved.

## Access and troubleshooting

The menu can appear with Planner write or manage access, but attaching Cork links requires the specific Planner write permission as well as Security read access. If a permitted-looking action fails, ask the MSP to check the role rather than repeatedly creating duplicates.

Creating or completing Planner work does not patch software, resolve a Cork event, or synchronize results back to Cork. Use the provider's authorized remediation process and verify the imported result later.

For Company support requests, start with the [Home AI Assistant](/user-guides/ticketing/open-a-ticket). For discussion at an existing meeting, use [Add to Meeting](/user-guides/security/add-to-meeting).

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Do several selected findings create several Planner items?">
    They create one grouped Planner item with links to the selected findings.
  </Accordion>
  <Accordion title="Does opening the draft create an item?">
    No. Save begins creation. If saving later fails while links are attached, check Planner before retrying.
  </Accordion>
  <Accordion title="Can I rely on Hide from Company users in this shortcut?">
    No. The current shortcut does not reliably persist that option. Verify visibility through the main Planner workflow before adding restricted information.
  </Accordion>
  <Accordion title="Why did a save error still leave an item in Planner?">
    Item creation and source linking happen separately. Review the existing item and its links before trying again.
  </Accordion>
</AccordionGroup>
